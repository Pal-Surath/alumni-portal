- **Project Name:** College Alumni Management Portal
- **Student:** Surath Pal
- **Semester:** 3rd Semester
- **Course:** BSc

- **University:** Visva-Bharati University

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP 8+
- MySQL
- Apache
- GitHub
- Railway

## Main Features

### Alumni

- Alumni registration
- Secure login
- Alumni profile
- Alumni directory
- Search alumni
- Filter alumni
- Graduation year information
- Company and job information
- Location information
- Profile status

### Administrator

- Secure admin login
- Admin dashboard
- Alumni statistics
- View registered alumni
- Search alumni
- Filter alumni by approval status
- Approve alumni
- Reject alumni
- Edit alumni information
- Delete alumni accounts
